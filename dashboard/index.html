How Signals Arrive

Argus does not compute indicators internally. It executes trades when TradingView sends a JSON webhook on each 30-minute bar close. You can use either mode below — include ema21 in the payload to enable the 21 EMA + 55 SMA stack.

The server places 10–14 DTE OTM options via Robinhood and manages profit-taking and stop ratchets automatically.

Alert JSON Templates
Mode A — 55 SMA only (default)
{"ticker":"SPY","event":"bar_close","close":{{close}},"sma55":{{plot("55 SMA")}},"option_price":{{plot("Option Price")}}}
Mode B — 21 EMA + 55 SMA stack
{"ticker":"SPY","event":"bar_close","close":{{close}},"sma55":{{plot("55 SMA")}},"ema21":{{plot("21 EMA")}},"option_price":{{plot("Option Price")}}}
Weekly expected move (partial exit)
{"ticker":"SPY","event":"weekly_move_hit","option_price":{{plot("Option Price")}}}

Replace SPY with SPXW, IWM, or QQQ per chart.
